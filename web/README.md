# Chengyu Clash — MVP 原型

面向欧美学习者的"用成语吵架"网页应用原型。纯静态、零依赖、零成本。

## 本地运行

直接双击打开 `index.html` 即可（无需服务器、无需安装任何东西）。

## 功能

- **📖 Dojo（成语道场）**：30 条精选吵架成语，按火力三级分类
  - Lv1 Passive-Aggressive 阴阳怪气 / Lv2 Direct Hit 指桑骂槐 / Lv3 Nuclear 诛心暴击
  - 每条含拼音、英文字面义、真实语用、实战例句、误用警示；支持中英文/拼音搜索、等级筛选
- **⚔️ Arena（吵架竞技场）**：与 3 种 AI 对手（论坛杠精 / 职场阴阳人 / 半桶水专家）进行 5 回合制对线
  - 点击成语卡片出招（专为不会打汉字的学习者设计）
  - 根据火力匹配度判定：命中 / 过度升级 / 火力不足，实时血条 + 回合战报
  - 结算含等级评定（S–D）与教练建议

## 接入真实 AI（当前为本地脚本模拟）

`app.js` 顶部的 `AI_CONFIG` 是接入点。上线前需要写一个极小的服务端代理（如 Cloudflare Worker）转发 LLM API，密钥不进浏览器。对局节奏、判分文案可全部由后端 prompt 控制，前端结构不变。

## 部署（零成本方案）

1. 把 `web/` 目录推到 GitHub
2. Vercel 或 Cloudflare Pages 导入仓库，自动获得 HTTPS 域名
3. 绑定自购域名（约 60 元/年，唯一成本）

## 文件结构

- `index.html` — 页面骨架（两个视图：Dojo / Arena）
- `style.css` — 深色主题样式，移动端自适应
- `data.js` — 成语库（30 条）+ 等级定义，加成语只改这个文件
- `app.js` — 图书馆渲染 + 对局引擎 + 战报，AI 后端接入点
